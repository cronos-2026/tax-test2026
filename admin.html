後台登入紀錄

主要管理員與次要管理員皆可使用後台功能；次要管理員不能新增管理員，也不能刪除登入紀錄。新增管理員帳號僅能由主要管理員在 Apps Script 指令碼屬性中設定。 登入紀錄由 Apps Script 後端於驗證成功時直接寫入 admin-login-log.json，瀏覽器無法新增或竄改；裝置識別、瀏覽器資訊與 IP 為瀏覽器自行回報，僅供參考，可能被偽造。連續登入失敗達上限而鎖定時，也會留下一筆紀錄。
登入後自動載入中央登入紀錄。
登入時間 帳號 裝置識別 公開 IP（用戶端回報） 瀏覽器／平台 結果 操作
全自動辨識： 登入頁不需要填寫電腦名稱。瀏覽器會自動建立穩定裝置識別，並隨登入請求回報可取得的瀏覽器／作業系統資訊與公開 IP，由後端寫入紀錄。 一般瀏覽器無法讀取 Windows／macOS 真正的主機名稱，因此「裝置識別」是系統自動建立的識別碼。 若安全環境限制部分裝置資訊，系統會自動降級，只保存能取得的資料；若公開 IP 查詢也被網路或防火牆阻擋，IP 會顯示「無法取得」。
