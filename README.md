# 創業組織稅負比較工具（2026.10.07_v21）

比較「獨資／合夥商號」與「公司」兩種組織型態的全年稅負（綜所稅、營所稅、股利課稅）。

## 檔案結構
- `index.html`：公開前台；`js/` 為各功能模組（設定、格式、扣除額、稅額引擎、計算、儲存、列印）。
- `admin.html`：後台。
- `tax-config.json`：前台使用的正式參數；`annual-presets.json`：113～115 年度預設。
- `data/annual-candidate.json`：年度公告候選資料，由 GitHub Actions 每週更新。
- `gas/Code.gs`、`gas/appsscript.json`：Apps Script 後端（登入、參數發布、登入紀錄）。
- `scripts/build.mjs`、`package.json`、`.github/workflows/deploy-pages.yml`：發布時建置（白名單、JS 混淆、解析驗證）並部署到 GitHub Pages。
- `scripts/check_tax_updates.py`、`.github/workflows/check-tax-annual.yml`：年度公告監控。
- `docs/history/`：歷次更新說明。

## 計算規則摘要
- 綜所稅：薪資＋營利所得（＋股利）－免稅額－標準扣除額－已啟用特別扣除額－基本生活費差額；未成年子女免稅額加計 50%。
- 股利：自動比較「合併計稅（抵減 8.5%、上限 80,000 元，超過應納稅額可退稅）」與「分開計稅 28%」。
- 公司：營所稅 12 萬以下免稅，12～20 萬按超過部分 1/2，超過 20 萬按 20%；稅後盈餘提列 10% 法定公積後全數分配。

## 後台：免稅額加成項目的顯示控制
「70歲以上免稅額」與「未成年子女免稅額加計 50%」各有兩個獨立選項：
- **啟用（納入計算）**：關閉後該項目不計算。未成年子女加計預設啟用。
- **前台顯示欄位**：取消勾選＝前台隱藏欄位。**隱藏只影響畫面，不影響計算**——欄位內的數值（預設 0）仍照常參與計算。

## 已知限制
- 基本生活費 213,000 元為 114 年度公告，115 年度公告後請於後台更新。
- 薪資所得特別扣除額預設未啟用，薪資族稅額會偏高，請於後台啟用。
- 未計算：列舉扣除、基本稅額（最低稅負）、二代健保補充保費、營業稅、未分配盈餘加徵，以及本人／配偶自身 70 歲以上的高齡免稅額。
- 結果僅供概算，不構成稅務意見。

## 安全原則
自動抓取的年度資料只寫入候選檔，須管理員在後台核對後，才會同步到正式 `tax-config.json`。管理員登入、參數發布與登入紀錄寫入全由 Google Apps Script Web App 處理；GitHub Fine-grained Token 與管理員密碼雜湊僅存於 GAS Script Properties，絕不傳到前端。

- 登入有失敗鎖定（5 次 / 15 分鐘），密碼以加鹽雜湊保存；登入紀錄由後端寫入，瀏覽器無法偽造（裝置與 IP 欄位為用戶端回報，僅供參考）。
- 主要管理員與次要管理員都可發布參數；次要管理員不能新增管理員、不能刪除登入紀錄。帳號設定僅由主要管理員在 GAS Script Properties 管理。
- 發布前由後端驗證參數結構與範圍，並以版次檢查避免覆蓋他人修改。
- Pages 發布版經建置混淆且不含 `admin-login-log.json`。混淆與 `Cronos` 來源標記只增加閱讀成本，不提供原始碼保密或安全保護。
- 部署與密碼設定請見 [`GAS-DEPLOY.md`](GAS-DEPLOY.md)。
